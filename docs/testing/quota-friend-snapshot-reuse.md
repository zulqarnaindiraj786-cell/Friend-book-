# Friendship snapshot read reduction

The read-only 60-minute sample documented in `quota-followup-chat-0083.md` identified an expensive `friends` duplicate-protection guard. This change does **not** remove that guard or solve its full-scan cost. It targets a smaller, independent redundancy in the same acceptance and unfriend flows: `readRow` already returns the exact canonical request, profile and friendship JSON, so a second point read of that snapshot before installing the atomic guard is unnecessary. The D1 batch still compares every snapshot and checks for duplicates and canonical shadowing. Legacy-only snapshots retain their original pre-read/conversion checks; concurrent changes still abort with 409. There is no schema migration or Android change.

With 200 unrelated mirrored friendships, local Miniflare D1 and the actual Worker measured one acceptance at **1,418 reads / 70 writes / 26 statements** before versus **1,415 / 70 / 23** after; unfriend measured **420 / 37 / 19** versus **417 / 37 / 16**. This saves three point reads, not the large historical-friendship scan; fixtures, D1 metadata and sampled analytics are not production billing. Races, forbidden actors, duplicates, historical/wrapped records, canonical shadowing, exact counters and transaction rollback remain covered by Worker tests.

The network-disabled SQLite replay now exercises 100 synthetic accepts and removals. Accept statements went **2,600 to 2,300**, returned rows **700 to 400**; unfriend statements **1,900 to 1,600**, returned rows **700 to 400**. Changed SQLite rows stayed 1,900 and 1,500 respectively. The complete run covered **38,688 requests and 64 query plans**, with no EXPLAIN errors; another run used waves of up to 200 with serialized local SQLite commits. Locally 190 Worker, nine schema/plan and 280 script tests passed. Run `QUOTA_QUERY_PLANS=1 node scripts/loadtest/d1_quota_replay.mjs 1000 1`, and copy the new workloads to the prior revision in an isolated checkout for comparison. Roll back to the prior Worker if needed. No production synthetic traffic was generated; real billed savings and device behavior are unmeasured.
