# Cloudflare production readiness check

This marker file schedules a production Worker redeploy and read-only D1 diagnostics from the deployment workflow. The diagnostics inspect only aggregate resource counts and newest document IDs/owners; they do not copy, mutate, or delete Firebase or D1 user data. It also checks Workers KV namespace provisioning. The current user reports that feed, chat, friend requests, likes, and comments still fail. Root collection queries now merge legacy app-document rows into the Firestore-compatible D1 query, with Firestore rows taking precedence for duplicate paths; the production read-only audit must validate this rollout.
