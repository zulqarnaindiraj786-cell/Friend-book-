# Quota audit and guarded no-op writes

The 06:09 screenshot shows 347.58k / 5M daily reads (6.95%) and 22.97k / 100k daily writes (22.97%). Compared with the 05:50 screenshot, the displayed cumulative counters grew approximately 47.33k reads and 4.84k writes. Rounded account-wide dashboard totals, time alignment and reporting delay prevent attribution to one query or change.

A subsequent read-only adaptive analytics run around 01:14 UTC showed substantially less recent activity than the earlier sampled burst: the listed five-minute shapes included 48 preferred-document lookup executions, four presence upserts and four canonical live-discovery reads. Its fifteen-minute shapes included comment reads, point lookups and 43 legacy-document upserts with 387 reported rows written. Analytics are sampled/adaptive; the upsert shape is shared by multiple operations, so it does not establish that the changes below caused or would have removed those writes.

For canonical root profiles, repeated literal merge PUTs that change nothing can now avoid a dual write and temporary guard writes. For canonical posts and reels, repeated literal edits or actor-scoped already-applied save/unsave operations can do the same after the normal authorization. The shortcut uses a single indexed read to check that the authorized canonical snapshot has not changed and that the legacy mirror already exactly matches the document and owner `writeRow` would persist. A changed canonical snapshot causes the normal retry and reauthorization; missing or stale mirrors still take the normal guarded write to repair them. Legacy-only rows are still promoted. Transforms other than the validated actor-scoped save and non-merge replacements stay on the original path. Skipped no-ops do not advance document update timestamps.

This trades up to two point reads for avoiding writes on the matching no-op paths; no-op frequency in production is unknown. Tests exercise unauthorized access, changed fields, privacy checks for repeated saves, raced snapshot changes, and stale/missing legacy mirrors. Local synthetic replay validates behavior, not D1 billing. This is not an app-wide quota cap, does not bound normal user activity, and should not be described as eliminating all quota usage.
