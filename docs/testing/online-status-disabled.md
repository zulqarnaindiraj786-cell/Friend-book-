# Online status disabled

At the owner's request, online green dots and last-seen are disabled separately from chat typing. `ONLINE_STATUS_DISABLED=true` disables presence session reads/writes and scheduled presence cleanup on the Worker; typing maintenance and the authenticated typing endpoint remain enabled. Legacy `/me` and `/contact` calls return an offline/zero-time response; the old presence socket receives HTTP 403, which the shipped Android socket adapter treats as non-retryable. Already-open sockets may continue on an old Worker version until they close; old clients can still make profile/authorization reads and can retain cached UI state. The server does not bulk-delete or rewrite presence/profile data.

Old Android profile heartbeat PATCHes of the exact five-field presence shape become write-free when the visibility preference is unchanged; a changed `showActiveStatus` is still persisted independently. Other profile edits, registrations and mixed writes remain on their normal path. Peer profile projection already omits private presence fields. The setting can be reversed in a future coordinated server/client release; no data migration is performed.

Android 172 / 2.10.30 disables presence initialization, socket, heartbeat and watchers, hides online/last-seen even from cached user data, and replaces the status toggle with an off notice. It retains the existing Cloudflare typing gate, typing indicator, messaging and calls. New installs and registrations no longer initialize `isOnline` true. Installed older clients require the new APK to remove their local watcher/heartbeat calls entirely.

Local validation covers disabled endpoints with no presence table access, typing and authorization, skipped R2/presence maintenance, old client profile writes, preference changes and normal edits, plus Android wiring (231 Worker tests, 295 script tests). Worker validation `45015514632` and deployment `45015514641` succeeded; Android compile and unit tests `45015514696` succeeded. Signed candidate build `45015660801` succeeded and published prerelease `friendbook-2.10.30-cloudflare-79bbea4`; installation is a separate check. R2/D1 data is retained for rollback. Aggregate usage is affected by many app features; presence was not established as the whole quota problem. Test fixtures and emulator success cannot quantify production savings or prove behavior on physical handsets.
