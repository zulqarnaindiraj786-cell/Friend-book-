# Coalesce story engagement snapshot guards

A first story view or changed reaction must atomically preserve the exact authorized story, viewer and author profiles, and trusted friendship state. Previously the Worker inserted four temporary guard rows, wrote the canonical story and its legacy mirror, then deleted those four guards. On the canonical-only path, the canonical upsert now embeds all four exact snapshot checks; if any changed, its `path NOT NULL` constraint aborts the D1 batch, and the Worker retries the complete reads and authorization. The mirror remains in the same batch. Historical-only story or profile records retain the original guard-based compatibility path. No schema, Android or push behavior changes.

Local Miniflare D1 with the real Worker and migrations through 0081 reported a synthetic first view at **9 reads / 20 writes / 13 statements** before, and **9 / 12 / 8** after. A repeated view remained **7 / 0 / 8**. Two simultaneous views by different users both succeeded without losing either view; a concurrent story change was retried; an author block prevented the view; and an injected mirror failure rolled back the canonical view. These synthetic D1 metadata include indexes, but are not account-wide billed usage or a capacity guarantee.

The Node/SQLite Worker regression also covers racing viewer bans, friendship removal, stale story updates, legacy-only story and viewer records, expiry, repeated view/reaction, and mirror rollback. In the network-disabled 1,000-user Worker replay, 999 first views changed **9,990 to 1,998** SQLite rows including guards and used **12,987 to 7,992** statements, with **4,995 returned rows** both times. The 999 repeated views wrote zero SQLite rows in both runs. SQLite change counts exclude index maintenance. The full replay covered 35,489 requests with 63 query plans and zero EXPLAIN errors. Locally 189 Worker, nine migration/plan and 280 script tests passed. No actual device, FCM or production load was tested. Rollback is the previous Worker code; no data migration is required.
