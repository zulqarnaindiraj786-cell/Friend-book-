# Profile and ordinary post guard coalescing

For an existing canonical profile or non-group post, guarded writes now compare the exact authorized document snapshot inside the canonical upsert. If it changed or disappeared, the NOT NULL constraint aborts the complete D1 batch and the existing mutation retry re-reads and reauthorizes; the canonical and legacy mirror still commit atomically. Missing and legacy-only records retain the previous temporary guards, including absence checks and promotion. Group posts use their separate membership/owner guard; other guarded collection types retain their prior path. No schema or Android change is required.

Actual Worker/Miniflare D1 local metadata (migrations through 0081): a changed profile edit measured **3 reads / 17 writes / 5 statements** before and **3 / 15 / 3** after; an actor-scoped first post save measured **7 / 18 / 9** and **7 / 16 / 7**. The reduction removes a temporary guard row and its deletion, not genuine canonical, mirror or index writes. These are synthetic measurements, not production billing or a capacity guarantee.

The offline SQLite real-Worker replay now includes 1,000 changed profile merges and 999 changed saves. Changed profile statements fell **6,000 to 4,000**, changed rows including triggers **4,000 to 2,000**; changed save statements fell **8,991 to 6,993** and changed rows **3,996 to 1,998**. Returned rows were identical. SQLite changes omit index maintenance. The full replay passed **37,488 requests**, including a wave of up to 200 concurrent requests against serialized local SQLite, and **63 query plans** without EXPLAIN errors. Reproduce with `QUOTA_QUERY_PLANS=1 node scripts/loadtest/d1_quota_replay.mjs 1000 1`; copy the added replay workloads to an isolated checkout of the previous revision for comparison.

Regression tests cover concurrent profile/friendship edits, a post save racing privacy or owner edits, unauthorized save attempts, unchanged saves, stale/missing mirrors, legacy profile promotion, and injected mirror failures with rollback. Miniflare separately exercised privacy, profile and post races and mirror rollback. Local full suites passed 189 Worker, nine schema/plan and 280 script tests. Local tests cannot establish production traffic frequency, actual device behavior or billed quota. Rollback is the prior Worker, without data migration; no production synthetic traffic or signed build is needed.
