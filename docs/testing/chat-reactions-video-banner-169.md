# Message reactions, phone video export and 50 dp banners

- The previous chat authorization allowed a non-sender to update receipts, but rejected the client's `reactions.<uid>` update. The Worker now allows a room member to modify only their own entries in the reaction/name/photo maps. Message content and other users' entries remain protected; the existing transactional room/message guards still apply. Direct and batch endpoints, add/change/remove, forged entries, outsiders, Team message membership, and racing membership/message changes were exercised locally. Production Worker deployment 45000451314 and read-only connectivity succeeded; no production test message was created. A Team broadcast's separate shared-reaction document has independent authorization and is not asserted to work across accounts by these tests.
- The screenshot reports a generic phone encoding failure; it does not reveal the underlying Media3 codec error. The Android change enables Media3's encoder fallback and adds a final H.264/AAC-compatible retry without forced mono, frame-drop or bitrate settings. It still encodes locally, preserves audio, scales the requested video heights, and does not upload the original as a substitute. Retries remove partial outputs and do not restart on a timeout; unit tests exercise this decision logic, not physical codecs or the user's original clip. Unsupported, damaged or unreadable files and device-specific codec failures may still fail; the fallback's encoded size can vary.
- Feed and Reels already requested `AdSize.BANNER` (320 × 50 dp) in this branch, without scaling/cropping. A shared size method and regression test make the 50 dp setting explicit for both placements. An older installed app may differ; live AdMob fill and a physical layout have not been checked.
- Version 169 / 2.10.27 is a test candidate, not a Play Store release. Backend changes can work with existing clients; video and UI changes require installing a compatible new APK. Do not claim handset video upload, all codec support, real-ad delivery, or cross-account Team broadcast reaction behavior until tested end-to-end.
